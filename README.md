# Módulo 8 - Reto 2

## Autora

Mónica Pachón Basallo

## Descripción

Proyecto de Ciencia de Datos Reproducible desarrollado para el Máster en Behavioral Data Science.

El proyecto utiliza datos de la European Social Survey (ESS Round 6) para analizar la relación entre bienestar subjetivo y factores sociodemográficos, familiares y económicos.

## Objetivo general

Analizar cómo distintos factores sociales, económicos y familiares se relacionan con el bienestar subjetivo en Europa.

## Estructura del repositorio

- Datos/: bases de datos originales y depuradas.
- Graficos/: visualizaciones generadas durante el análisis.
- scripts/: código utilizado para limpieza, análisis y dashboard.
- informes/: informe técnico reproducible.
- presentacion/: presentación reproducible.

## Herramientas utilizadas

- R
- RStudio / Posit Cloud
- R Markdown
- GitHub
- ESS Round 6
